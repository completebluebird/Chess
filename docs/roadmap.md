[자동] = Claude Code가 테스트로 확인, [수동] = 박범혁이 Unity에서 확인. 마일스톤 1개 = 스레드 1개, 기능 1개 = PR 1개.
현재 마일스톤: **M6**

## M1. 보드와 이동 (큐브 프로토타입)

- [x] [수동] 카메라가 항상 보스를 보고 어지럽지 않음

## M2. 폰 공격과 보스 체력
작업: Q/E 대각선 공격, 보스 체력, 초록 칸, 공격 가능할 때 보스 깜빡임, 칸 상태 레이어, 임시 히트스톱·플래시, 디버그 HUD.

- [x] [수동] Q/E로 보스 체력을 0까지 깎을 수 있음

## M3. 보스 공격 4종과 빨간 예고
작업: 패턴 데이터(칸+타이밍), 예고→판정 공통 시스템, 점점 진해지며 깜빡이는 빨간 칸, 레이저·운석·물기·브레스(벽 생성), 브레스 안전 경로(BFS), 보스 회전·고개 돌리기, 패턴 선택 AI.
- [x] [자동] 예고 칸과 판정 칸 일치, 예고 없는 피해 0건
- [x] [자동] 임의 시드 1,000회에서 브레스 벽까지 제한 시간 내 도달 경로 존재
- [ ] [수동] 빨간 칸만 보고 모든 공격 회피 가능 (색 끄고 깜빡임만으로도 구분)

## M4. 피격, 화상, 무적, 플레이어 체력
작업: 불 계열 즉발+화상 도트, 화상은 지속시간만 갱신, 물기 즉발 고데미지, 무적 0.3~0.5초, 플레이어 체력과 패배.
- [x] [자동] 화상 비중첩, 무적 중에도 화상 지속
- [x] [자동] 다단히트 브레스 정면 피격도 최대 피해 이내

## M5. 각성 (룩·비숍·나이트, PR 3개)
공통: 게이지·슬로모션·착지 보정·착지 직후 무적을 먼저 구현.
1. 룩: W·S 직선 관통(S는 바깥 끝에서 꺾여 복귀)과 보스 바로 앞 정지, 이동한 고리 수만큼 추가딜·후딜. A·D는 1번 고리에서만 연속 타격하고 출발 칸에 복귀, 다른 고리는 공격 실패+게이지 소모.
2. 비숍: 두 키 동시 입력 0.1초 버퍼, 4방향 대각선 관통(SD·SA는 바깥 끝에서 꺾여 복귀), 이동한 고리 수만큼 추가딜·후딜, 오른쪽 90도 착지.
3. 나이트: 두 키 순서 입력, 수직 아닌 조합 무시, 후보 두 칸 초록 표시, 점프와 광역딜, 보스 착지 시 복귀.
- [x] [자동] 비숍 착지 (내 위치 (18,4)에서 WD→(23,1), WA→(15,1), SD→(5,1), SA→(9,1))
- [x] [자동] 룩 A·D는 1번 고리에서만 성립하고 한 바퀴 뒤 출발 칸에 소멸, 다른 고리는 실패+게이지 소모
- [x] [자동] 룩·비숍 추가딜과 후딜이 이동한 고리 수(꺾여 돌아온 고리 포함)로 계산됨
- [x] [자동] 나이트 8방향 입력 전부, WS·AD·WW 무시
- [x] [자동] 판 밖 착지 후보는 표시·선택되지 않음
- [x] [자동] 막힌 착지 칸은 가장 가까운 빈 칸으로 밀림
- [ ] [수동] 제한시간 안에 세 기물 모두 헷갈리지 않고 발동 가능

## M6. 전투 루프와 게임 흐름
작업: 체력 구간(70%, 40%) → 브레스 → 스턴+슬로모션 → 복귀 상태 머신, 승리·패배, 타이틀·일시정지·재시작, 승리 화면(클리어 시간, 다시 하기, 타이틀).
- [x] [자동] 상태 전이 테스트, 같은 구간에서 브레스 두 번 나오지 않음
- [ ] [수동] 타이틀→전투→승패→재도전이 끊김 없음
- [x] [자동] 느린 브레스: 일반 공격으로 나오고 벽·스턴이 없음, 칸당 회전 시간이 이동 쿨다운보다 김 (M6-3)
- [ ] [자동] 바닥 찍기: 스턴 뒤에 나오고 공중에서는 보스가 맞지 않음, 착지 때 고리마다 차례로 판정 (M6-4, 구현 예정)
