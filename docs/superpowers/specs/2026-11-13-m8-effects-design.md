# M8 이펙트와 카메라 연출 설계

작성일: 2026-11-13 · 개정: 2026-11-14 (사용자와 항목별 검토 후) · 상태: 사용자 승인 대기
기반 문서: `docs/design/phase1.md`의 "뷰" 절, `docs/roadmap.md`의 M8, `docs/design/tuning.md`

## 의도

규칙은 이미 Core에서 끝나 있다. M8의 목표는 플레이어가 **지금 무슨 일이 일어났는지 화면만 보고 알 수 있게** 만드는 것이다. 공격 종류, 피격 원인, 각성 상태가 색과 모양과 움직임으로 구분되어야 한다. 아트는 M9에서 교체하므로, 이번에는 캡슐·큐브·칸 색과 Unity 기본 파티클로 충분히 읽히게 한다.

## 목표

1. 일반 공격(Q/E)과 각성 공격이 모양과 손맛(히트스톱 길이)으로 구분된다.
2. 각성 연출(검은 불꽃)과 화상 연출(발밑 불씨)이 서로 다른 모양과 방향이어서 헷갈리지 않는다.
3. 피격 종류 4가지(물기, 레이저, 화염, 운석)가 화면과 폰 움직임으로 구분된다.
4. 각성한 기물 3종(룩·비숍·나이트)이 불꽃 색으로 구분된다.
5. 기획서 이펙트 표 10종과 카메라 요구(가림 반투명, 각성 줌인·줌아웃)를 모두 넣는다.

## 비목표

- 아트 교체와 모델링 (M9)
- 음원 제작과 믹싱 (M9). 이번에는 소리 호출 지점만 만든다.
- 무료 이펙트 팩. M8은 기본 파티클만 쓰고, 팩 사용 여부는 M9에서 다시 확인한다.
- 2페이즈 연출, 잡몹 연출
- 규칙 변경. 공격 판정, 데미지, 쿨다운은 Core에서만 바꾼다.
- 각성 중 룩·비숍의 공격 가능 칸(초록) 표시. 지금은 나이트 첫 키 입력 뒤에만 초록 칸이 나온다. 알고 있는 빈틈으로 두고 이번에는 다루지 않는다.
- 신규 보스 공격(느린 브레스, 바닥 찍기)의 연출. 해당 공격이 구현될 때 이 문서의 규칙(아래 "착탄과 피격")을 그대로 적용한다.

## 안티 목표

- 연출 때문에 판정이 흐려지면 실패다. 예고 칸(빨강)과 판정이 어긋나면 안 된다.
- 화면 효과가 강해서 보스나 폰, 빨간 칸이 안 보이면 실패다. 화면 가장자리 효과는 폰이 있는 화면 아래 가운데를 가리지 않는다.
- 카메라 연출이 입력을 막으면 실패다.

## 제약

- Core에는 `UnityEngine`을 쓰지 않는다. 연출은 `ChessBoss.Game`에만 둔다.
- 숫자는 `BattleTuning` 에셋에 두고, 임시값은 `docs/design/tuning.md`에도 적는다.
- 씬·프리팹 YAML을 손으로 고치지 않는다. 이펙트와 UI 레이어는 코드로 생성한다.
- 새 패키지를 추가하지 않는다. 흔들림은 이미 설치된 Cinemachine의 Impulse를 쓴다.

## 시간 규칙

| 상황 | 게임 로직·보스·폰 이동 | 파티클 | 카메라·화면 효과·UI |
|---|---|---|---|
| 평소 | 진행 | 진행 | 진행 |
| 히트스톱 | 멈춤 | 멈춤 | **진행** |
| 슬로모션 (각성 0.6배, 스턴 0.5배) | 느려짐 | 느려짐 (각성 불꽃·빛 기둥만 실제 시간) | **실제 시간으로 진행** |
| 일시정지·결과 화면 | 멈춤 | 멈춤 | **멈춤** (그 순간 상태로 정지) |

- 카메라는 실제 시간으로 움직여야 하므로 `CinemachineBrain.IgnoreTimeScale`을 실행 시 코드로 켠다.
- 화면 효과는 unscaled time으로 돌리되 `BattleTime.IsPaused`면 진행을 멈춘다.
- "다시 하기"로 씬을 다시 불러도 시간 배율과 화면 효과가 남지 않아야 한다.

## 접근 방식

**A. 코드로 이펙트 생성 (채택)**: `Game/Effects/` 아래에 `ParticleSystem`과 UI 레이어를 코드로 만든다. 모든 연출이 한곳에서 관리되고 PR마다 diff가 작다. 단점은 파티클을 인스펙터에서 한눈에 튜닝하기 어렵다는 것이다.

**B. 프리팹으로 만들기**: 눈으로 튜닝하기 쉽지만 `.meta`와 YAML 변경이 크고 CLAUDE.md가 금지한 방식이다.

**C. URP Volume(비네팅)으로 화면 효과**: 초안에서 고려했으나 채택하지 않는다. 물기 번쩍임·화면 불·저체력 비네팅이 비네팅 값 하나를 서로 덮어쓰고, 씬에 포스트 프로세싱 설정이 없어 씬 변경이 필요하며, 비네팅은 불꽃처럼 보이지 않는다.

화면 가장자리 효과는 **코드로 만든 uGUI 전체 화면 레이어를 효과마다 하나씩** 둔다 (`MenuPanel`과 같은 방식). 겹쳐도 각자 보인다. 예외는 브레스 아지랑이로, 화면 왜곡 셰이더(URP Full Screen Pass)가 필요해 마지막 PR로 분리한다.

## 카메라

### 기본 구도
- 폰과의 거리를 지금의 2/3로 당긴다: `CinemachineFollow.FollowOffset` (0, 5, -6) → 약 (0, 3.3, -4).
- 거리만 줄이면 폰이 화면 아래로 밀리므로 시야각을 40 → 50으로 넓힌다.
- 이 값들은 지금 씬 파일에만 있다. `BattleTuning`으로 옮기고 시작 시 코드로 적용해 Unity에서 바로 조정할 수 있게 한다.

### 가림 반투명
- 가리는 경우는 둘이다. 벽이 폰보다 바깥쪽 같은 줄에 있을 때, 그리고 비숍·나이트로 보스 건너편에 착지한 직후 카메라가 따라오는 동안의 보스.
- 벽과 보스 머리에는 충돌체가 없으므로 물리 레이캐스트 대신 **카메라와 폰을 잇는 선분이 렌더러 bounds를 지나는지**로 판정한다.
- 가린 물체는 알파 0.3으로 0.15초에 걸쳐 흐려지고, 벗어나면 같은 시간에 돌아온다. 윤곽선은 넣지 않는다.
- 프로토타입 재질은 불투명 하나뿐이다. 실행 중 셰이더 키워드를 바꾸면 빌드에서 변형이 빠질 수 있으므로 **반투명 재질 에셋을 하나 추가**한다.

### 각성 줌인·줌아웃 (실제 시간)
1. 0~0.25초: 폰으로 빠르게 줌인.
2. 0.25~0.6초: 평소보다 **넓게** 줌아웃.
3. 대기 중: 넓은 화면 유지.
4. 종료 시: 0.2초에 걸쳐 평소 구도로 복귀.

카메라가 움직이는 중에도 입력을 막지 않는다. 줌 도중 방향 입력이나 피격으로 각성이 끝나면 즉시 4번으로 넘어간다.

### 흔들림과 기울임
- 흔들림은 Cinemachine Impulse로 낸다 (카메라 transform을 직접 움직이면 Cinemachine이 덮어쓴다). 리스너와 소스는 코드로 붙인다.
- 강도 3단계: 약함(레이저 착탄, 나이트 착지, 각성 공격 적중), 강함(운석 착탄, 물기).
- 기울임(`Lens.Dutch`): 물기·운석에 **맞았을 때만** 3~5도 기울었다가 약 0.25초에 복귀. 크게 기울이지 않는다 (피격 후 무적 0.4초 안에 빨간 칸을 다시 읽어야 한다).

## 연출 목록

### 일반 공격과 각성 공격

| 대상 | 트리거 | 연출 |
|---|---|---|
| 일반 공격 (Q/E) 적중 | `PawnActions.TryAttack` 결과 Hit | 보스 쪽 대각선으로 흰 호(0.15초) + 보스에 스파크 + 히트스톱 0.05초 |
| 일반 공격 빗나감 | 결과가 Hit이 아님 (쿨다운 제외) | 짧고 얇은 호만. 히트스톱 없음 |
| 비숍, 룩 W/S | `AwakenedStrike.Path` | 경로를 따라 흰 창 궤적, 끝에서 밝은 스파크 |
| 룩 A/D | `AwakenedStrike.Path` | 고리를 훑는 흰 호, 칸마다 작은 스파크 |
| 나이트 | 착지 | 착지 칸 주변 먼지 링 + 약한 흔들림 |
| 각성 공격 적중 | 폰이 보스에 **닿는 순간** | 보스 번쩍임 + 히트스톱 **0.1초** + 약한 흔들림 |

지금 코드는 방향키를 누른 순간 `BossView.PlayHit`을 불러서, 폰이 날아가는 0.25초 전에 맞은 표시가 먼저 나온다. 데미지 계산(Core)은 그대로 두고 번쩍임·히트스톱 시점만 도착 순간으로 옮긴다.

### 각성

| 대상 | 트리거 | 연출 |
|---|---|---|
| 각성 시작 | 1/2/3 입력 성공 | **검은 불꽃**이 폰을 감싸며 아래에서 위로 솟음 + **빛 기둥** 0.3초 + 줌인. "투캉!" 소리 호출 |
| 각성 중 | `Awakening.Active != null` | 검은 불꽃 유지. 슬로모션은 기존 0.6배 그대로 (새로 넣지 않음) |
| 발동으로 종료 | 방향 입력 | 불꽃이 위로 흩어지며 사라짐 |
| 취소로 종료 | 피격 또는 시간 초과 | 불꽃이 툭 꺼짐 |

기물 구분: M9 모델 교체 전까지 불꽃 가장자리(림라이트)와 빛 기둥 색을 기물마다 다르게 한다. 임시값은 룩 보라, 비숍 파랑, 나이트 초록.

### 화상과 상태 표시

| 대상 | 조건 | 연출 |
|---|---|---|
| 화상 | `PlayerVitals.IsBurning` | **발밑에서 꺼지는 주황 불씨**, 위로 조금 올라가다 사라짐. 각성 불꽃과 색·위치·방향이 모두 다름 |
| 게이지 가득 참 | `Awakening.Gauge >= 1` | 폰이 빛남 (색 맥동) |
| 저체력 비네팅 | 체력 비율이 임계 이하 | 화면 가장자리가 붉게 (전용 UI 레이어) |

### 착탄과 피격

착탄(판정이 떨어지는 순간)과 피격(플레이어가 실제로 맞음)을 나눈다. 착탄 연출은 **피해도 나온다.**

| 공격 | 착탄 (피해도 나옴) | 피격 (맞았을 때 추가) |
|---|---|---|
| 레이저 | 약한 흔들림 + 줄을 따라 불꽃 파티클 | 화면 불 약함 + 폰 휘청 |
| 운석 | 강한 흔들림 + 착탄 칸 파티클 | 기울임 + 폰 휘청 + 화면 불 약함 |
| 물기 | 강한 흔들림 | 와그작 소리 호출 + 화면 붉은 번쩍임(약 0.6초) + 기울임 + 폰 휘청 |
| 브레스 | 흔들림 없음. 빔이 폰과 가까울수록 강해지는 **아지랑이** (벽 뒤에 있어도 동일) + 빔 칸 불꽃 파티클 | 화면 불 강함 + 폰 휘청 |

- 피격 종류는 `PlayerVitals.Hurt`가 불리는 시점의 `BossAttacks.CurrentAttack`으로 안다. 착탄은 `AttackTimeline.Struck`으로 안다. Core 변경은 필요 없다.
- 아지랑이 세기는 폰의 둘레 칸과 빔 머리(`AimSector`) 사이 거리로 정한다. 빨간 칸을 흐리지 않게 화면 가장자리 위주로 약하게 넣는다. 카메라에 안 보이는 뒤쪽에서 빔이 다가올 때 신호 역할을 한다.
- 화면 불은 화면 가장자리의 불꽃 UI 레이어다. 화상 불씨(폰 발밑)와 별개다.

### 기획서 이펙트 표 대응

| 이펙트 (기획서 표) | 상태 | 이 문서의 위치 |
|---|---|---|
| 화면 흔들림 | 신규 | 흔들림과 기울임, 착탄과 피격 |
| 파티클 | 신규 | 착탄과 피격 |
| 화면 불 효과 | 신규 | 착탄과 피격 |
| 화상 표시 | 신규 | 화상과 상태 표시 (발밑 불씨로 변경) |
| 히트스톱 0.05초 | 있음 | 각성 공격만 0.1초로 구분 |
| 보스 피격 플래시 | 있음 | 각성 공격은 도착 순간으로 시점 이동 |
| 스턴 슬로모션 | 있음 | 변경 없음 |
| 게이지 가득 참 | 신규 | 화상과 상태 표시 |
| 각성 | 신규 | 각성 |
| 저체력 비네팅 | 신규 | 화상과 상태 표시 |

## 구조

연출을 두 종류로 나눈다.

- **한 번짜리 (이벤트)**: 슬래시, 창 궤적, 스파크, 착탄, 흔들림, 번쩍임. 호출부가 필요한 정보(방향, 경로, 칸 목록)를 넘긴다.
- **상태 (매 프레임 읽기)**: 각성 불꽃, 화상 불씨, 게이지 발광, 저체력 비네팅, 아지랑이, 가림 반투명. Core 상태를 매 프레임 읽어 켜고 끈다. 끄는 이벤트를 놓쳐 남는 일이 없다. 기존 `ShowAwakening`, `SetHittable`과 같은 방식이다.

파일:
- `Game/Effects/BattleEffects.cs`: 씬의 한 컴포넌트. 한 번짜리 연출의 진입점(`Slash(from, to, hit)`, `Lunge(path)`, `Impact(kind, cells)`, `PlayerHurt(kind)` 등). static으로 두지 않는다 (씬 재시작 시 파괴된 객체 참조 방지). 기존 컴포넌트가 실행 시 `AddComponent`로 붙여 씬 파일을 고치지 않는다.
- `Game/Effects/ScreenEffects.cs`: uGUI 레이어(붉은 번쩍임, 화면 불, 저체력 비네팅). 일시정지 규칙을 여기서 지킨다.
- `Game/Effects/CameraEffects.cs`: 기본 구도 적용, 각성 줌, Impulse 흔들림, 기울임, 가림 반투명.
- `Game/Effects/PawnEffects.cs`: 폰에 붙는 상태 연출(각성 불꽃, 화상 불씨, 발광)과 휘청.
- `Game/Effects/SoundCues.cs`: 소리 호출 지점만. 이름(`awaken`, `slash`, `bite`…)을 상수로 두고 실제 재생은 M9에서 채운다.
- 호출부: `PawnController`(공격·각성·착지·도착 순간 적중), `BossAttackView`(착탄·피격).

## 튜닝 항목 (`BattleTuning`과 `docs/design/tuning.md`에 추가)

- 카메라 오프셋, 시야각, 각성 줌인·줌아웃 거리와 각 구간 시간
- 가림 반투명 알파(0.3)와 전환 시간(0.15초)
- 흔들림 강도 2단계와 지속시간, 기울임 각도(3~5도)와 복귀 시간(0.25초)
- 각성 공격 히트스톱(0.1초)
- 화면 붉은 번쩍임 지속시간(0.6초), 화면 불 세기 2단계

## 결정 기록 (2026-11-14, 사용자)

- 각성에 빛 기둥 추가, 화상은 발밑 불씨, 무료 팩은 M9에서 확인, 이펙트는 10종 기준.
- 카메라 거리 2/3과 시야각 50, 가림 판정은 선분 방식.
- 착탄은 피해도 흔들림, 기울임은 물기·운석만 작게, 브레스는 흔들림 대신 아지랑이.
- 각성 줌아웃은 평소보다 넓게, 기물은 불꽃 색으로 구분.
- 각성 적중 표시는 도착 순간으로, 각성 공격은 히트스톱 0.1초와 약한 흔들림.
- 각성 중 룩·비숍 초록 칸은 보류.
